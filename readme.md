# Agent Fundamentals

Learning the mechanical foundations of AI agents from scratch.

## What's here
- `01_first_call.py` — basic LLM API call
- `02_memory.py` — conversation history and how agents remember
- `03_tools.py` — single tool calling
- `03b_tools_practice.py` — multiple tools, parallel calling, agent loop
